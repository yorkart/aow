# PR 详情验证

运行 `npm run test:pr` 检查状态映射、外部链接、缺失日期和 Diff 模型释放；后端使用 `cargo test -p aow-server pull_requests` 验证 Provider 协议、remote 匹配和配置升级。

运行 `npm run preview:pr`，打开 http://127.0.0.1:5199/tests/pull-request-preview.html。预览使用独立测试数据，只拦截 PR 查询，不连接真实代码托管服务。测试服务拒绝所有非 GET 请求并记录请求方法。

浏览器验证：

- 概览展示作者、时间、分支、审阅人、标签、里程碑和统计，描述支持折叠。
- 检查按名称与状态筛选，展开失败检查可查看输出。
- 讨论保留首条评论和全部回复，筛选未解决讨论不展示已解决讨论。
- 文件按路径筛选，可展开并排/统一 Diff，两侧不可编辑；二进制文件显示说明。
- 切换内容标签后从顶部阅读；在 390px、600px 和桌面宽度无横向溢出。
- 键盘方向键/Home/End 可切换内容标签。

在预览 URL 上追加 `?scenario=...` 可验证其他场景：`empty`（无数据）、`partial`（部分请求失败）、`error`（首次请求失败）、`refresh-error`（刷新失败保留已有详情）、`diff-error`（首次 Diff 失败，可重试）、`long`（长标题与分支）、`readonly`（HTML 输入框、表单和可编辑内容被禁用/移除）。

## 手机站

同一测试服务的 `/m` 运行完整手机站。进入普通工作区，点击底部 PR，验证搜索、编号/分支显示和草稿标记，再打开详情。切换概览/文件变更/检查/讨论，确认单列 Diff 原行/新行编号与增删符号正确、无可编辑控件。用返回按钮与浏览器返回确认列表搜索与位置保留；刷新详情链接确认可直达。另两个工作区可检查空列表和请求失败提示。

可用 `PR_PREVIEW_PORT=5200 npm run preview:pr` 指定独立端口。
