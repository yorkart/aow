# Agent icons

These assets identify the corresponding agents in the aow. They are
bundled locally; rendering the icons does not contact external services.

Sources:

- `codex.png`: the icon published by OpenAI for its [Codex VS Code extension](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt), downloaded from [the official extension asset endpoint](https://openai.gallery.vsassets.io/_apis/public/gallery/publisher/openai/extension/chatgpt/latest/assetbyname/Microsoft.VisualStudio.Services.Icons.Default).
- `hermes.png`: the unchanged Apple touch icon from [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent/blob/main/website/static/img/apple-touch-icon.png), copied from the installed Hermes 0.18.0 source on 2026-09-25.
- `claude.png`: the icon served by the [Claude website](https://claude.com/) at [claude.com/icon.png](https://claude.com/icon.png).
- `trae.png`: the public TRAE brand favicon linked by the [TRAE website](https://www.trae.cn/), downloaded unchanged from [its official asset endpoint](https://lf-cdn.trae.com.cn/obj/trae-com-cn/trae_website_prod_cn/favicon.png) on 2026-09-24. This is the TRAE brand mark, not a separately verified CLI 2.0 logo.

The Codex and Claude assets were retrieved on 2026-09-07.

The original artwork and colors are preserved. Brand marks belong to their
respective owners.
