GOOD TO KNOW

开始之前，
你可能想了解。

AoW 是什么？+

AoW（Agent-oriented Workbench）是面向 AI Agent 的浏览器开发工作台。它运行在你自己的电脑或服务器上，把 Git 项目、Worktree、文件、Terminal、Agent 会话和自动化集中到一个界面。

需要把代码上传到 AoW 吗？+

AoW 直接访问运行机器上的仓库和文件，不要求上传到一个托管的 AoW 服务。Agent CLI 如何使用模型服务，取决于你为相应工具配置的账号和服务。

可以使用哪些 Agent？+

终端可运行你已安装的 CLI。AoW 为 Codex、Claude Code 和 TraeCode CLI 提供会话、识别及自动化等集成；请先在运行 AoW 的机器上安装对应 CLI 并登录。不同 Agent 的具体能力以使用文档为准。

支持哪些系统？手机需要安装应用吗？+

安装包支持 Linux、macOS 的 x86_64 和 ARM64。手机通过浏览器访问同一个服务地址即可使用移动界面，无需安装独立应用。手机必须能够访问 AoW 所在的网络。

怎么访问远程服务器上的 AoW？+

默认只监听 127.0.0.1:8282，可以通过 SSH 隧道访问。可信内网或 VPN 可配置监听地址；公网使用需要 HTTPS 和额外的访问控制。查看访问配置。

关闭网页，任务还会继续吗？+

终端由 terminald 管理；关闭网页不等于停止终端。自动化任务由系统定时器触发独立 Runner。运行机器及相关服务需要保持可用；未配置应用层补跑或自动重试。
